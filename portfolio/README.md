# 💼 Portfólio Pessoal de Desenvolvedor

Portfólio moderno, responsivo e autoral desenvolvido com **HTML5, CSS3 modular e JavaScript puro (ES6+)**.

## 🎨 Identidade Visual
- **Tema Principal:** Dark (#101014) com cards em grafite (#1C1825).
- **Cor Primária:** Roxo `#8B5CF6`.
- **Cor Secundária:** Lilás `#C4B5FD`.
- **Elemento Central do Hero:** Terminal Interativo de Código simulado (sem uso de foto pessoal).
- **Suporte a Temas:** Alternância instantânea entre Dark e Light com persistência em `localStorage`.

## 📁 Estrutura do Projeto
```text
portfolio/
├── index.html                 # Página única semântica
├── README.md                  # Documentação do projeto
└── assets/
    ├── css/
    │   ├── variables.css      # Tokens de design e paletas de cores
    │   ├── reset.css          # Reset moderno
    │   ├── base.css           # Tipografia e utilitários
    │   ├── components.css     # Botões, terminal, badges, cards
    │   ├── layout.css         # Header fixo, containers e footer
    │   ├── sections.css       # Estilos das seções
    │   └── animations.css     # Keyframes e efeitos de rolagem
    ├── js/
    │   ├── data/
    │   │   ├── projects-data.js # Lista de projetos
    │   │   └── skills-data.js   # Lista de competências
    │   ├── modules/
    │   │   └── theme.js         # Módulo de tema Dark/Light
    │   └── main.js              # Ponto de entrada
    └── images/
        ├── icons/
        └── projects/
```

## 🚀 Como Executar
Abra o arquivo `index.html` em qualquer navegador web ou utilize a extensão Live Server no VS Code.
